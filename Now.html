§ 05.1Focus

Four threads open at once, each for a different reason.

What I'm actually spending hours on. If something isn't on this list, I'm not working on it — regardless of what an older page might say.

  1. 01 Starting out with Go. Working through the official Tour and writing throwaway scripts to get a feel for goroutines, interfaces, and the tooling. Next step: a small CLI — probably a log parser or a file organiser — to have something to point at. The reason is concrete: I want a language with a single-binary deployment story and no runtime to ship alongside. Learning
  2. 02 AI Chat SDK — streaming + adapters. Framework-agnostic chat widget on StencilJS and Web Components. Currently wiring up streaming responses (SSE + chunked decoding) and a pluggable adapter layer so the same widget drops into Vue, React, or plain HTML hosts without a rewrite. Build
  3. 03 Nuxt 3 → Nuxt 4 migration at Apple. Large Vue 3 / Nuxt 3 component library moving to Nuxt 4. Working through the compatibility layer, untangling auto-import edge cases, and rethinking lazy-loading boundaries so individual components tree-shake cleanly when the library is consumed as a package. Contract
  4. 04 Backend fundamentals, deeper. Postgres schema design and query performance, and rebuilding a slice of a payroll service in Express + Sequelize to pressure-test my own patterns against what production actually demanded. Laravel on the side for contrast — different dialect, same argument. Study
